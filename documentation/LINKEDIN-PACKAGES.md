## Active Directory Administration Lab

Built an interactive Active Directory workflow simulation with user onboarding, account lockout investigation, password reset actions, group membership and computer objects. Visitors can review the synthetic directory, make changes and export local audit evidence.

## PowerShell IT Automation Toolkit

Created a safe browser toolkit for exploring IT reporting workflows, validated bulk CSV inputs and execution history. ## Security Event Investigation Lab

Built a Windows authentication investigation simulation using synthetic 4624, 4625 and 4740 events. Visitors can apply supported event filters, compare authentication patterns, save investigation notes and export incident evidence. Includes a clearly defined SPL subset rather than a live Splunk instance.

Skills: Splunk · Security Monitoring · Incident Investigation · Windows Security · Log Analysis
