# Self-hosted fonts

Manrope and Space Grotesk variable TrueType fonts are distributed under the SIL Open Font License 1.1. Their full copyright and licence notices are included alongside each font.

Source: official Google Fonts repository, downloaded 16 November 2026.

- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk

The website loads these local files without requests to Google Fonts or another CDN. Fonts use font-display: swap and system fallbacks.
